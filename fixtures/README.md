# Synthetic regression images

All images here are generated test patterns, not device captures or user photographs.
`formats/synthetic.*` is one synthetic pattern encoded in several formats.
`formats/pipe-large.jpg` is deterministic RGB noise (Python Random seed 20261029,
768 × 768, GdkPixbuf JPEG quality 95), used to detect partial stdin reads.
Fixtures and tests are provided under GPL-3.0-only; see ../compat/LICENSE.
