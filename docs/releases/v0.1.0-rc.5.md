# WeTypeX Omarchy 0.1.0-rc.5

Preview candidate for Arch / Omarchy x86_64. This candidate separates ordinary package installation and updates from local development. It is not a stable release.

## Changes

- Native update controls use the shared package client for checking, downloading, verifying, installing and resuming. Cancelled authorization retains downloaded assets; corrupt caches require a new verified download.
- A source-only bootstrap installer supports first installation and migration from rc.4 without a source checkout or compiler. It requires system Python and GitHub CLI 2.93 or later. Initial installation uses a visible terminal authorization and pacman transaction.
- New release bundles contain tag-bound build attestations for verification without a GitHub account. Verification failures stop installation; checksums alone do not authorize an update.
- A fixed-purpose Polkit helper independently validates the protected package before installation. Installing a package does not restart Fcitx or activate synchronization.
- The installation guide separates official runtime preparation, input-method configuration, service activation and device association. Opening it performs none of these operations.
- Development builds are labeled and disable production update controls. Development tools build, test and preview in isolated directories.
- Fix a settings shutdown crash caused by process-completion callbacks accessing destroyed controls. The update panel and installation guide disconnect these callbacks before destruction.

## Validation and limits

The maintenance working tree passed all 13 local CTest suites. The shutdown regression reproduced SIGSEGV before the fix and passed afterwards; the actual settings-window test passed 20 consecutive runs. Those earlier results included pre-existing local responsive-layout edits, which are excluded from this candidate. The selected candidate was then exported from the Git index, rebuilt separately against host Qt 6.11.2 and passed all 13 suites in 8.56 seconds. Its source file hashes matched the selected index. Clean Arch package-transaction verification remains required before publication.

The candidate build baseline is the Arch archive dated 2026/10/01, whose Qt 6.11.2-3 matches the maintenance host. Matching that dependency is not proof of complete binary compatibility. The exact-tag workflow must finish successfully and the resulting public verification bundle must be checked. No new real-device transfer acceptance or pristine-machine installation result is claimed.

## Installation

Follow [the release installation guide](../RELEASE-INSTALL.md) using the explicit preview channel after publication. Retain a compatible prior package for recovery. Existing account, runtime, pairing and user preferences must remain in place. Official runtime 2.2.3.657 is obtained separately; this release distributes adapter code only.
