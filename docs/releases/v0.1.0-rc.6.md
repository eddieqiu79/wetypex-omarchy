# WeTypeX Omarchy 0.1.0-rc.6

Preview candidate for Arch / Omarchy x86_64, using official runtime 2.2.3.657 separately. This patch makes the native settings window usable in narrower tiled windows and at higher display scaling. It includes the previously retained local responsive-layout work and extends it with content measurements and regression checks.

## Changes

- Permit resizing down to 480 × 320 logical pixels. Choose the initial size using available screen space and compact the sidebar in narrow windows. Navigation entries retain their full label as a tooltip.
- Wrap setting titles and descriptions. Let rows grow vertically instead of fixing their height.
- Stack shortcut descriptions and key groups when their measured content no longer fits side by side. Measure key labels using the actual font, rather than character counts and a fixed key height.
- Expose horizontal scrolling when content cannot fit, preserving access instead of silently clipping it. Normal page navigation and vertical scrolling remain available in short windows.
- Add checks for five widths (480, 600, 720, 960, 1280), two heights (320, 540), four scale factors (100%, 125%, 150%, 200%), long descriptions, 18-point text, navigation reachability and brand-label clipping.

## Evidence and limits

The local build passed all 13 CTest suites after the layout changes. Offscreen screenshots were inspected; a clipped brand label found during inspection was corrected and covered by an assertion. The final expanded short-window matrix also passed, covering all eight pages in 40 size/scale combinations. The exact-tag release workflow must pass before publication. Offscreen checks do not establish behavior on every compositor, font configuration, monitor arrangement or scaling factor.

The changes affect settings layout only. Input, synchronization and file-transfer protocols are unchanged, and no new device interoperability result is claimed. There is no account, runtime or configuration migration. The installed settings application must be closed and reopened to display the new layout; running input/sync services do not need to restart for this UI patch.

## Installation and recovery

Use the preview channel after publication, following [the release installation guide](../RELEASE-INSTALL.md). Build against the reviewed Arch archive dated 2026/10/01 and verify the resulting dependency set. Retain the compatible rc.5 package for package-level rollback; this is not a user-state rollback. No official runtime, pairing identity or personal data is distributed.
