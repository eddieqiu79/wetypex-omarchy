# WeTypeX Omarchy 0.1.0-rc.3

Preview release for Arch / Omarchy x86_64. This candidate includes the `rc.2` native desktop applications and subsequent clipboard reliability fixes. It is not a stable release.

## Changes since rc.2

- Treat an explicitly empty Wayland clipboard as an empty selection, allowing incoming clipboard content to be processed. Actual clipboard read errors remain errors.
- Terminate timed-out account request process groups so descendants cannot indefinitely retain the shared identity lock. The existing lock scope, request timeout and polling intervals remain unchanged.
- Record bounded, owner-only request timing and failure metadata in `sync-health.json`, without clipboard content, identities, tokens or URLs.
- Add English and Chinese README, contributing and licensing guides.

## Evidence and limits

The maintenance desktop applied the clipboard changes to its existing private-prefix installation. A Mac test string reached the Linux clipboard and matched across the available text representations. In a later short observation, 25 requests succeeded without timeouts; median request duration was 795 ms and the maximum was 922 ms. This is not an end-to-end latency measurement or proof of long-term stability. The synthetic timeout regression checks that a child process releases its test lock; it does not prove an orphan caused the earlier user-reported issue. See [connection diagnosis](../sync-connection-diagnosis.md).

The previous candidate's isolated GUI received user confirmation of file transfers in all four Linux ↔ Mac/iPhone directions; no cross-device byte hash comparison was reported. This release has not repeated the full device matrix or been installed and activated on a clean desktop. Desktop migration, sleep/wake, reconnect, long-duration operation and large-file behavior remain to be validated.

## Installation and licensing

Use `v0.1.0-rc.3` with the preview channel as described in [the installation guide](../RELEASE-INSTALL.md). Stable discovery excludes candidates. Runtime `2.2.3.657` is obtained separately under the applicable terms. No official engine, dictionaries, extracted UI, identities or personal test content is included. The existing upstream and component license notices remain applicable.

Direct cross-device file copy/paste is not implemented. File transfers use the dedicated window. Keep a compatible prior package and follow the documented explicit downgrade procedure if recovery is needed; an adapter downgrade is not a whole-system or account-state rollback.
